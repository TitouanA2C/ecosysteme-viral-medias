# L'Écosystème Viral — médias des landing pages

Images et vidéos utilisées par les pages ClickFunnels de L'Écosystème Viral (page « Nos clients, leurs résultats »).
Servies par GitHub Pages : `https://titouana2c.github.io/ecosysteme-viral-medias/<dossier>/<fichier>`.

- `posts/` — posts de réussite (WebP, 720 px de large)
- `avant-apres/` — captures de reels avant / après (WebP, 540 px de large)
- `temoignages/` — témoignages vidéo (MP4 H.264 720p) + affiches (WebP)

Ne pas renommer ni supprimer de fichier : les pages en ligne y font référence.
